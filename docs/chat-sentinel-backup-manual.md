# 聊天守护使用说明

## 它是什么

聊天守护是 SillyTavern 的本地恢复工具。它在聊天变化后，从服务器已经保存好的 `.jsonl` 文件创建独立快照。

它不会：

- 把聊天正文上传到网络；
- 调用模型或任何外部 API；
- 让浏览器把当前加载到的聊天全文重新写回服务器；
- 修改 SillyTavern 核心、角色卡、预设或其他扩展。

## 打开页面

在 SillyTavern 的扩展设置中找到 `聊天守护`。抽屉里只有：

- 本地存储健康摘要；
- `打开聊天守护` 按钮。

完整功能都在打开后的独立管理界面中。

## 首页：聊天守护

首页显示：

- 自动守护是否开启；
- 当前角色/群聊和具体聊天；
- 最近一次成功快照；
- 当前聊天已有版本数；
- 本地存储是否健康。

主操作只有 `立即保护当前聊天`。`查看备份历史` 是次级入口。

低频操作位于更多菜单：

- `保护这个角色的全部聊天`；
- `选择要保护的聊天`。

## 备份历史

### 当前聊天

只显示现在打开的具体聊天。每行包括时间、消息数、相对上一版的变化、长期保留状态和快照类型。

### 全部聊天

先按角色或群聊、再按具体聊天分组。搜索可以匹配角色名、群聊名和聊天 ID。

### 回收站

从历史删除的版本会先进入回收站。SillyTavern 中主动删除的聊天，其现有守护版本也会进入回收站。

- 普通版本可 `放回历史`；
- 主动删除的聊天可 `恢复聊天`；
- `永久删除` 会实际删除快照文件，无法撤销。

证据不足的旧文件会显示在 `待归属旧备份 / 隔离项`。它们仍以原文件名留在磁盘，不会被猜测归入同名聊天，也不会被自动清理。

## 版本详情

点击一个版本后，右侧或移动端下方显示：

- 聊天、时间、消息数和状态；
- 最近几轮预览；
- `长期保留`；
- `恢复到这个版本`；
- 更多菜单中的 `移到回收站`。

`长期保留` 只是索引状态，不再通过重命名文件来表达，因此不会破坏文件名解析。

## 恢复时会发生什么

点击 `恢复到这个版本` 后，插件会：

1. 确认这个快照确实属于目标聊天；
2. 逐行校验整个 JSONL；
3. 如果目标聊天文件存在，先创建 `恢复前保险` 快照；
4. 用临时文件写入并刷盘；
5. 原子替换目标；
6. 目标聊天、群聊元数据、保险快照和索引一起提交；后续任一步失败时整体回滚。

完成提示会明确显示保险快照文件名。保险快照会自动设为长期保留。

如果快照中任意一行损坏，恢复会拒绝开始，不覆盖目标聊天。

## 异常缩水

当历史完整基线较大，而当前聊天突然只剩很少消息时，自动守护会拒绝写入，并显示基线与当前消息数。

如果这是你主动进行的大幅删改：

1. 点击 `立即保护当前聊天`；
2. 阅读基线和当前消息数；
3. 点击 `保护旧版并继续`。

系统会先把旧完整基线设为长期保留，再把新状态保存成明确标记的 `人工确认删改` 快照。阈值不会因此降低。

## 设置

设置页只包含：

- `自动守护`；
- `最短间隔`：同一聊天的密集事件会合并；
- `每聊保留数`：普通快照的上限；
- 存储位置与健康；
- 安装版本。

不同聊天有独立的 debounce 和串行队列。聊天 A 的事件不会取消或延迟聊天 B；同一聊天在快照执行中再次变化，会在当前任务完成后补一次。

## 文件和旧数据

默认用户的目录：

```text
data/default-user/backups/sentinel-chat/
```

快照文件名包含：

- 毫秒时间；
- `char` 或 `group`；
- 可读标签；
- canonical identity；
- 随机唯一 ID；
- 消息数；
- `auto`、`manual`、`confirmed` 或 `pre-restore` 状态。

角色改名不会改变 canonical identity，因为身份只使用用户作用域、角色头像/群 ID 和聊天文件路径语义。

升级时会创建 `.sentinel-chat-index.v2.json`。旧快照：

- 保留原文件名；
- 不自动移动或删除；
- 先登记为可见隔离项；
- 只有能唯一证明用户作用域、稳定实体 ID 和聊天文件身份时才归入新聊天；
- 同 chatId 跨角色或证据不足时不猜归属；
- 不再产生旧 identity 的新增写入。

如果索引损坏，损坏原件会先隔离保存，健康状态会显示 `需要检查`。重建只能恢复可证明的事实，不能推导的长期保留、回收站和 hash 不会被假装恢复。明确确认修复前，插件会阻止自动保留清理和永久删除。

核对隔离项后，可在设置页点击 `核对后解除清理锁` 并阅读确认说明。确认只解除清理锁，不会把隔离文件强行归属，也不会补造无法推导的元数据。

## 安装与更新

安装当前 checkout：

```bash
./install-or-update.command
```

只更新 Git 源码：

```bash
./scripts/update-source.command
```

安装器不会删除未知目录。它先验证前后端两个源码目标和两个安装入口，再创建 staging 链接；已确认属于本插件的旧安装会留下 `.bak-时间` 备份。若第二个链接切换失败，第一个链接和两个旧安装都会自动恢复。

安装或更新服务端插件后，需要在你明确授权时重启 SillyTavern。只刷新浏览器无法重新加载服务端代码。
